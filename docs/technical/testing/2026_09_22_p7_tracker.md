- **UC-4** : signup → login JWT → company onboarding (pivots) → missions ×2 (pivots user_missions/mission_companies) → CRA → entries ×2 liées aux missions → totaux serveur (1,0 j / 65 000 cents) → submit → lock → **commit Git Ledger réel** (hash 40 hex, message contractuel `CRA locked — cra:<uuid>`) → double lock 409 sans delta de commits → protection entry 409 → état final GET cohérent.
