# Mémoire fc08::022 — Scripts Ruby versionnés = périmètre Quality Gates

## fc08::022
<!-- created: 2026-10-24 -->
<!-- validated: 2026-10-24 (CTO — formulation corrigée : « Gates applicables au dépôt ») -->
**Leçon (incident-CI 24/10 — tracker P6, §7)** : un script Ruby versionné hors de `app/`, notamment dans
`scripts/`, doit être contrôlé par les Quality Gates **applicables au dépôt**. Dans l'incident du 24 octobre
2026, une erreur de parsing dans `scripts/coverage_gap_analysis.rb` a fait échouer simultanément Brakeman
(exit 7) et RuboCop (26 offenses de niveau F). **Règle opérationnelle** — lorsqu'un script Ruby est introduit
ou modifié : (1) exécuter localement RuboCop et Brakeman selon les commandes utilisées par la CI du dépôt ;
(2) corriger les erreurs avant le push ; (3) vérifier que le fichier est bien inclus dans le périmètre des
contrôles ; (4) obtenir une CI verte avant de considérer le script certifié. **Preuves** : incident et
correction au tracker P6 §7 · commit correctif `aedd70e4` · CI de la PR #82 : run 40121939127 (6/6 checks
réussis). **Principe** : un script versionné n'est pas certifié simplement parce qu'il n'a jamais été exécuté
par la CI — sa première introduction doit inclure la preuve de passage des contrôles applicables.
