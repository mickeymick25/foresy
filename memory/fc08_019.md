# fc08::019 — Scripts Ruby versionnés = périmètre Quality Gates

**Date :** 2026-10-24
**Origine :** incident-CI documenté dans `docs/technical/p6_coverage_implementation_tracker.md`, §7.

## Leçon

Un script Ruby versionné hors de `app/`, notamment dans `scripts/`, doit être contrôlé par les
Quality Gates applicables au dépôt. Dans l'incident du 24 octobre 2026, une erreur de parsing
dans `scripts/coverage_gap_analysis.rb` a fait échouer simultanément Brakeman et RuboCop.

## Règle opérationnelle

Lorsqu'un script Ruby est introduit ou modifié :

1. Exécuter localement RuboCop et Brakeman selon les commandes utilisées par la CI du dépôt.
2. Corriger les erreurs avant le push.
3. Vérifier que le fichier est bien inclus dans le périmètre des contrôles.
4. Obtenir une CI verte avant de considérer le script certifié.

## Preuves

- Incident et correction : tracker P6, §7.
- Commit correctif : `aedd70e4`.

## Principe

Un script versionné n'est pas certifié simplement parce qu'il n'a jamais été exécuté par la CI.
Sa première introduction doit inclure la preuve de passage des contrôles applicables.
